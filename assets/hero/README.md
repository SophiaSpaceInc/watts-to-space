All files are 1280 × 720 JPEG (16:9) and have no text in the image. The page title is set in HTML, so crop to a wider banner as needed. The art is right-weighted, with open space on the left for the title.

## How they were made

- **Tool:** Grok Bot's built-in AI image generator, from text prompts. Later versions used the earlier drafts as style references, the everyday images used `home-hero-v3.jpg`, and v2 also used everyday v1.
- **Style:** an engineering-plate look in this site's palette, taken from `styles.css`. That means charcoal `#16181d` and slate `#3e4654` and `#7d8594` on paper `#f3f4f6`. The only accent is `--accent` `#7c2d22`, shading to `#e7a08c`, and it marks radiated heat.
- **Iteration:** v1 had the radiator facing Earth. For v2 and v3, Chris pointed to the Starmind layout, with the arrays and radiator perpendicular to each other and edge-on to nadir.
- **Known flaw:** the generator only approximates the geometry. In v2 and v3 the 90° between radiator and wings doesn't read perfectly, and a few heat lines start near the arrays instead of only at the radiator. Redraw as a vector diagram if exactness matters.
